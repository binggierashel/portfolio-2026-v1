2. GasGuard — Household LPG Gas Leak Detection & Monitoring System (MQ-2 & ESP32)

IoT & Embedded Systems Project

Designed and built an IoT-based household LPG gas leak detection and fire prevention system using an ESP32 microcontroller and MQ-2 gas sensor. The device monitors gas concentration (PPM) in real time on an integrated OLED display and web dashboard, triggers a mini exhaust fan via relay when gas levels rise, and sends instant alert notifications via Telegram Bot.

ESP32 Microcontroller MQ-2 Gas Sensor Real-Time Web Dashboard OLED Display & Exhaust Relay Telegram Bot API
GasGuard Hardware Unit & OLED Display Completed IoT detector unit featuring an MQ-2 gas sensor, OLED status screen (real-time PPM, safety status, fan state, and local IP), LED indicator, alarm buzzer, and top-mounted mini exhaust fan.
GasGuard Real-Time Web Dashboard Interactive web interface displaying live MQ-2 PPM gauge, min/avg/max statistics, real-time PPM chart, manual/automatic exhaust fan relay controls, ESP32 online status, and Telegram Bot alert thresholds.
Project Team & Hardware Demonstration Team documentation at IPB Vocational School with the completed GasGuard household LPG gas leak monitoring prototype.
